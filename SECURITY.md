# Security Policy

## Reporting a vulnerability

Do not include confidential workbook content, credentials, access tokens, personal data, or proprietary formulas in a public issue.

For a suspected vulnerability, privately contact the repository owner through an appropriate private channel available on their GitHub profile. Include a minimal reproduction, affected version, impact, and suggested mitigation when possible.

## Scope

Relevant reports include unintended modification of source worksheets, exposure of workbook content, unsafe external communication, formula injection in generated output, and denial-of-service behavior on realistic workbook sizes.
